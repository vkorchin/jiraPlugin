# Quick Start Guide

## Быстрый запуск без Maven

Если в системе нет Maven, можно запустить проект напрямую с Java:

### 1. Компиляция

```bash
# Создать директорию для скомпилированных классов
mkdir -p target/classes

# Скомпилировать все Java файлы
find src -name "*.java" | xargs javac -d target/classes -cp target/classes
```

### 2. Запуск демонстраций

```bash
# Основное демо (обработка событий, откаты, производительность)
java -cp target/classes com.eventstream.demo.EventStreamDemo

# Демо с пользовательскими обработчиками (банковские операции)
java -cp target/classes com.eventstream.demo.CustomEventHandlerDemo
```

## Результаты демонстрации

### Основное демо показывает:
- ✅ Обработку 5000+ событий за ~143ms
- ✅ Откат состояний за 0-2ms (цель <100ms достигнута)
- ✅ 100% успешность обработки событий
- ✅ 98%+ покрытие снимками для оптимизации

### Демо банковских операций показывает:
- ✅ Пользовательские обработчики событий
- ✅ Бизнес-логику (депозиты, снятия, заморозка счета)
- ✅ Обработку ошибок (попытка снятия с замороженного счета)
- ✅ Откат к состоянию до заморозки

## Архитектурные особенности

1. **Потокобезопасность**: ConcurrentHashMap, ReadWriteLock
2. **Производительность**: Copy-on-Write, снимки состояний
3. **Расширяемость**: Простое добавление новых типов событий
4. **Надежность**: Обработка ошибок, восстановление состояний

## Структура проекта

```
src/main/java/com/eventstream/
├── model/           # Модели данных (Event, EntityState, Snapshot)
├── stream/          # Источники событий (EventStream)
├── handler/         # Обработчики событий (EventHandler)
├── state/           # Управление состояниями (StateManager)
├── snapshot/        # Снимки состояний (SnapshotManager)
├── processor/       # Основной движок (EventProcessor)
├── rollback/        # Сервис откатов (RollbackService)
└── demo/           # Демонстрационные приложения
```

## Кастомизация

Для добавления нового типа событий:

1. Создайте класс, реализующий `EventHandler`
2. Зарегистрируйте его в `EventHandlerRegistry`
3. Система автоматически начнет обрабатывать новые события

Пример в `CustomEventHandlerDemo.java`.

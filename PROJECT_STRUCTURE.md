## 🔍 Детальное описание

### 📁 `src/main/java/com/eventstream/core/`

**Основные классы системы - ядро Event Stream Processor**

#### `Event.java`
- **Назначение**: Представление события в потоке
- **Ключевые поля**:
  - `entityId` - идентификатор сущности
  - `timestamp` - временная метка события
  - `eventType` - тип события
  - `payload` - данные события
  - `sequenceNumber` - порядковый номер события
- **Особенности**: Иммутабельный класс, валидация входных данных

#### `Entity.java`
- **Назначение**: Представление состояния сущности
- **Ключевые поля**:
  - `id` - идентификатор сущности
  - `state` - текущее состояние (ConcurrentHashMap)
  - `lastUpdated` - время последнего обновления
  - `lastEventSequence` - номер последнего события
  - `version` - версия состояния
- **Особенности**: Copy-on-write подход, потокобезопасность

#### `EventStreamProcessor.java`
- **Назначение**: Главный процессор событий
- **Ключевые возможности**:
  - Обработка входящих событий
  - Откат состояний на произвольную временную точку
  - Управление обработчиками событий
  - Создание снимков состояний
- **Особенности**: Многопоточность, асинхронная обработка

### 📁 `src/main/java/com/eventstream/handlers/`

**Обработчики различных типов событий**

#### `EventHandler.java`
- **Назначение**: Интерфейс для обработчиков событий
- **Методы**:
  - `canHandle(String eventType)` - проверка возможности обработки
  - `handle(Event, Entity)` - обработка события
  - `rollback(Event, Entity)` - откат события

#### `DefaultEventHandler.java`
- **Назначение**: Базовый обработчик по умолчанию
- **Особенности**: Универсальная обработка любых типов событий

#### `UserEventHandler.java`
- **Назначение**: Обработчик событий пользователей
- **Поддерживаемые типы**:
  - `USER_CREATED` - создание пользователя
  - `USER_UPDATED` - обновление пользователя
  - `USER_DELETED` - удаление пользователя

#### `OrderEventHandler.java`
- **Назначение**: Обработчик событий заказов
- **Поддерживаемые типы**:
  - `ORDER_CREATED` - создание заказа
  - `ORDER_UPDATED` - обновление заказа
  - `ORDER_CANCELLED` - отмена заказа
  - `ORDER_COMPLETED` - завершение заказа

### 📁 `src/main/java/com/eventstream/storage/`

**Системы хранения и управления данными**

#### `EventStore.java`
- **Назначение**: Хранилище событий для каждой сущности
- **Структура данных**: `ConcurrentHashMap<String, ConcurrentSkipListMap<Instant, Event>>`
- **Ключевые возможности**:
  - Добавление событий
  - Поиск событий по временному диапазону
  - Получение событий до указанного времени
  - Очистка старых данных

#### `Snapshot.java`
- **Назначение**: Снимок состояния сущности в определенный момент
- **Ключевые поля**:
  - `entityId` - идентификатор сущности
  - `entity` - состояние сущности
  - `timestamp` - время создания снимка
  - `eventSequenceNumber` - номер события

#### `SnapshotManager.java`
- **Назначение**: Управление снимками состояний
- **Ключевые возможности**:
  - Автоматическое создание снимков
  - Поиск ближайшего снимка
  - Очистка старых снимков
  - Статистика по снимкам

### 📁 `src/main/java/com/eventstream/utils/`

**Утилиты и инструменты тестирования**

#### `PerformanceBenchmark.java`
- **Назначение**: Бенчмарк производительности системы
- **Тесты**:
  - Обработка событий
  - Откат состояний
  - Нагрузочное тестирование
  - Измерение производительности

### 📁 `src/main/java/com/eventstream/`

**Примеры использования системы**

#### `Example.java`
- **Назначение**: Простой пример использования
- **Демонстрирует**:
  - Создание процессора
  - Регистрацию обработчиков
  - Обработку событий
  - Откат состояний

#### `AdvancedExample.java`
- **Назначение**: Расширенный пример с несколькими типами сущностей
- **Демонстрирует**:
  - Работу с пользователями и заказами
  - Параллельную обработку
  - Сложные сценарии отката
  - Производительность системы
